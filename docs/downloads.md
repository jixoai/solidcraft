# FDE2E SolidCraft downloads

This fork has not published branded installers or confirmed a public browser deployment.
Build from source using [building.md](building.md); published packages, when available, will
appear in [jixoai/solidcraft releases](https://github.com/jixoai/solidcraft/releases).

Do not install upstream packages or community-store entries expecting the WebMCP/Worker
implementation or FDE2E branding. Upstream signing certificates and store ownership do not
carry over to this fork. No signing or notarisation claim is made for future fork packages.

The desktop update checker accepts release pages and download assets only from
`https://github.com/jixoai/solidcraft/releases/`; it never falls back to upstream binaries.
No release, offline access and GitHub rate limits may leave updates unavailable.

Existing binary names, package asset names, design extensions and application/storage IDs
remain compatible. See [../FORK.md](../FORK.md) and [fork-maintenance.md](fork-maintenance.md)
before preparing or deploying a release.
